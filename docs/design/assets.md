# Assets for selected variant 3

The exact third displayed image chosen by the user is `selected-variant-3.png` (1487 × 1058 pixels). It is design reference material, not a rendered application background.

Image Gen created the two avatar portraits, tileable felt and card-back texture in the same direction. The application serves these from `apps/frontend/public/avatars/` and `apps/frontend/public/textures/`. The original application card fronts and furniture remain in use. Generated portraits are masked by ordinary circular image presentation.

- DM Sans: Fontsource distribution, SIL Open Font License; `public/licenses/dm-sans-OFL.txt`.
- Phosphor icons: `@phosphor-icons/react`, MIT; `public/licenses/phosphor-icons-MIT.txt`.
- Previously bundled Alegreya: SIL Open Font License; `public/licenses/alegreya-OFL.txt`.
- Local apartment lighting: Poly Haven Lebombo, CC0; `public/hdri/ATTRIBUTION.md`.

The source depicts twelve revealed personal cards during a draw prompt. Actual play hides unknown values and initially reveals two cards. The implementation preserves those rules and actual participant names, scores and microphone state instead of inserting the source's example state.
